# Locale1

Sito di prova per **Bar Locale1** — una caffetteria/bar dimostrativa, realizzato in HTML, CSS e JavaScript senza dipendenze o build step.

## Struttura

```
index.html      pagina unica (hero, chi siamo, menu, galleria, orari, contatti)
css/style.css   stile del sito (palette caffè/crema, layout responsive, dark mode automatica)
js/script.js    menu mobile, tab del menu, form di contatto (demo, non invia dati)
```

## Anteprima locale

Basta aprire `index.html` in un browser, oppure servire la cartella con un server statico, ad esempio:

```bash
python3 -m http.server 8000
```

e visitare `http://localhost:8000`.
